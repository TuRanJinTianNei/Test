## 🎯 项目概述

本项目是一个完整的OFDM（正交频分复用）系统仿真与信号处理工具集，包含：

1. **OFDM系统完整仿真**：发送端 → 信道传输 → 接收端处理
2. **信号生成与处理**：16QAM调制、IFFT/FFT、循环前缀、加窗
3. **信道建模**：Jakes瑞利衰落信道 + AWGN加性高斯白噪声
4. **信号分析**：功率谱密度估计、带宽估计、性能评估
5. **可视化分析**：多幅图形展示时域、频域、星座图、BER-SNR曲线等

### 2. 工具函数（Utility Functions）

#### 2.1 调制解调模块
- **`qam16.m`** - 16QAM调制函数
  - 功能：将比特流调制为16QAM复数符号
  - 输入：比特流（行向量，长度为4的倍数）
  - 输出：16QAM复数符号序列

- **`demoduqam16.m`** - 16QAM解调函数
  - 功能：对接收到的16QAM符号进行硬判决解调
  - 方法：最小欧氏距离准则
  - 输入：接收到的复数符号序列
  - 输出：解调后的比特流

#### 2.2 信道处理模块
- **`jakesChannel.m`** - Jakes模型瑞利衰落信道
  - 功能：创建并配置comm.RayleighChannel对象
  - 配置：三径多径、采样率15.36MHz、最大多普勒100Hz
  - 输出：配置好的瑞利衰落信道对象

- **`pilot_equalization.m`** - 导频辅助信道估计与均衡
  - 功能：基于导频的信道估计和零迫均衡（ZF）
  - 方法：线性/样条插值
  - 输入：FFT后的接收信号、导频位置、数据位置
  - 输出：均衡后的数据子载波、信道估计结果

#### 2.3 信号处理模块
- **`rcoswindow.m`** - 升余弦窗函数生成器
  - 功能：生成升余弦窗函数，用于OFDM符号平滑加窗
  - 目的：降低频谱旁瓣，减少带外辐射
  - 输入：滚降系数beta、窗长度Ts
  - 输出：升余弦窗向量

#### 2.4 功率谱密度估计模块
- **`estimateBandwidthPSD.m`** - 功率谱密度估计
  - 功能：使用Welch算法和AR模型法估计PSD
  - 方法：
    - Welch算法（周期图平均法）
    - AR模型法（Burg算法）
  - 输入：已处理的信号、采样频率、SNR
  - 输出：Welch和AR两种方法的PSD估计值

- **`estimateBandwidthFromPSD.m`** - 从PSD估计带宽
  - 功能：提供多种方法从PSD估计信号带宽
  - 方法：
    - 阈值法（固定/自适应）
    - 能量百分比法（如90%能量带宽）
    - 峰值下降法
    - RMS带宽法（二阶矩法）
    - 积分法（累积功率法）
  - 输入：PSD（dB）、频率向量
  - 输出：估计带宽、详细结果结构体

## 📖 详细文件说明

### 主程序文件详细关系

#### test1.m

**功能**: OFDM系统完整仿真程序（当前主程序）

**调用关系**:
```
test1.m
    ├── qam16.m                    (16QAM调制)
    ├── rcoswindow.m               (升余弦窗生成)
    ├── jakesChannel.m             (瑞利衰落信道，可选)
    ├── pilot_equalization.m      (导频均衡，可选)
    └── demoduqam16.m              (16QAM解调)
```

**主要流程**:
1. **发送端处理**:
   - 随机比特流生成
   - 16QAM调制 (`qam16.m`)
   - 导频插入（可选）
   - 频域子载波映射（共轭对称）
   - IFFT变换
   - 添加循环前缀(CP)和后缀
   - 升余弦加窗 (`rcoswindow.m`)
   - 符号重叠相加（LTE风格）

2. **信道传输**:
   - Jakes瑞利衰落信道 (`jakesChannel.m`，可选)
   - AWGN加性高斯白噪声

3. **接收端处理**:
   - 串并转换，去除CP和后缀
   - FFT解调
   - 信道估计与均衡 (`pilot_equalization.m`，可选)
   - 16QAM解调 (`demoduqam16.m`)
   - BER计算

**可视化配置**:
- **当前状态**: 部分可视化版本，Figure 2-8 被注释（单符号分析和加窗对比）
- **启用的Figure**: 1, 9, 10, 11, 12, 13, 14, 15
- **禁用的Figure**: 2, 3, 4, 5, 6, 7, 8
- **启用完整可视化**: 取消注释 Figure 2-8 的代码即可

**注意**: 
- `test2.m` 和 `test3.m` 当前不在主目录中
- 如需完整可视化，可编辑 `test1.m` 取消相关 Figure 的注释

#### signalGenerate.m

**功能**: OFDM信号生成函数（可独立运行）

**调用关系**:
```
signalGenerate.m
    ├── qam16.m                    (16QAM调制)
    ├── rcoswindow.m               (升余弦窗生成)
    └── (可选) estimateBandwidthPSD.m (PSD估计)
```

**特点**:
- 仅生成发送信号，不包含接收处理
- 可独立运行，生成信号保存在变量 `Tx_data` 中
- 可用于信号生成和后续分析

#### test_estimateBandwidthPSD.m

**功能**: 带宽估计功能测试程序

**调用关系**:
```
test_estimateBandwidthPSD.m
    ├── signalGenerate.m           (信号生成)
    ├── estimateBandwidthPSD.m     (PSD估计)
    └── estimateBandwidthFromPSD.m (带宽估计)
```

**流程**:
1. 生成OFDM信号
2. 估计功率谱密度（Welch和AR方法）
3. 从PSD估计带宽（多种方法）
4. 可视化结果

### 工具函数详细说明

#### 调制解调模块

**qam16.m** ↔ **demoduqam16.m**

- **qam16.m**: 将比特流映射到16QAM星座点
  - 输入：比特流（每4位一组）
  - 输出：16QAM复数符号（I+jQ）
  - 星座映射：4×4格点，最小距离归一化

- **demoduqam16.m**: 从接收符号恢复比特流
  - 方法：最小欧氏距离判决
  - 输入：接收到的复数符号
  - 输出：解调后的比特流

**关系**: 两者使用相同的星座映射表，确保调制解调一致性

#### 信道处理模块

**jakesChannel.m** → **pilot_equalization.m**

- **jakesChannel.m**: 创建瑞利衰落信道对象
  - 配置：三径多径、采样率15.36MHz、最大多普勒100Hz
  - 输出：comm.RayleighChannel对象

- **pilot_equalization.m**: 补偿信道影响
  - 输入：FFT后的接收信号、导频位置
  - 方法：基于导频的信道估计 + 零迫均衡
  - 输出：均衡后的数据子载波

**关系**: jakesChannel创建信道，pilot_equalization补偿信道影响

#### PSD估计模块

**estimateBandwidthPSD.m** → **estimateBandwidthFromPSD.m**

- **estimateBandwidthPSD.m**: 估计功率谱密度
  - 方法：Welch算法、AR模型法（Burg）
  - 输出：PSD估计值（dB）、频率向量

- **estimateBandwidthFromPSD.m**: 从PSD估计带宽
  - 输入：PSD估计值、频率向量
  - 方法：阈值法、能量百分比法、峰值下降法等
  - 输出：估计带宽、详细结果

**关系**: estimateBandwidthPSD的输出作为estimateBandwidthFromPSD的输入

## 🔧 配置说明

### 系统参数（在test1.m中配置）

```matlab
% 基本频率参数
subcarrier_spacing = 15e3;      % 子载波间隔：15 kHz
fs = 15.36e6;                   % 采样频率：15.36 MHz

% IFFT/FFT参数
IFFT_bin_length = 1024;          % IFFT点数

% 子载波配置
carrier_count = 300;             % 有效数据子载波数
symbols_per_frame = 50;          % 每帧OFDM符号数
total_symbols = 100;              % 总符号数

% CP配置
GI = 72;                         % 循环前缀长度

% 加窗配置
beta = 1/16;                     % 加窗滚降系数

% 信道参数
targetSNRdB = 15;                % 目标信噪比（dB）
use_rayleigh_fading = true;      % 是否使用瑞利衰落
fd = 100;                        % 最大多普勒频移（Hz）

% 导频参数
use_pilot_equalization = true;   % 是否使用导频均衡
pilot_spacing = 6;               % 导频间隔
interpolation_method = 'linear';  % 插值方法
```

## 📝 注意事项

1. **文件路径**: 确保所有工具函数文件与主程序在同一目录下，或在MATLAB路径中

2. **MATLAB版本**: 建议使用MATLAB R2016a或更高版本

3. **内存要求**: 
   - 当前test1.m配置（部分可视化）内存占用较小
   - 启用完整可视化（Figure 2-8）需要较多内存用于图形显示

4. **运行时间**:
   - test1.m: 当前配置较快（部分可视化）
   - 启用完整可视化后运行时间会稍长
   - signalGenerate.m: 中等（仅信号生成）

5. **数据保存**: 
   - PSD数据可保存为.mat文件，避免重复计算
   - 使用`save`和`load`命令管理数据文件
