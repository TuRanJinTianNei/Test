## 🎯 概述

本文档详细说明`2.带宽估计(功率谱）/`目录下的文件结构、依赖关系和使用方法。该模块实现了完整的OFDM信号带宽估计功能，采用**两步法**：先进行功率谱密度（PSD）估计，再从PSD估计信号带宽。

**目录位置**: `2.带宽估计(功率谱）/`

**核心功能**:
1. **功率谱密度估计** - 使用Welch算法和AR模型法（Burg算法）估计信号PSD
2. **带宽估计** - 提供5种不同的带宽估计方法从PSD中提取信号带宽
3. **完整流程** - 整合PSD估计和带宽估计，提供一站式解决方案

**设计特点**:
- ✅ 模块化设计，各功能独立可调用
- ✅ 支持独立运行模式，自动检测或生成信号
- ✅ 提供多种PSD估计方法和带宽估计方法
- ✅ 完整的可视化输出和结果对比
- ✅ 详细的文档和代码注释

## 📖 核心文件说明

### 1. estimateBandwidth.m ⭐ 主函数

**功能**: 完整的带宽估计流程，整合PSD估计和带宽估计两个步骤。

**函数签名**:
```matlab
[B_welch, B_ar, B_ideal, results] = estimateBandwidth(...
    sig_processed, fs, carrier_count, subcarrier_spacing, varargin)
```

**主要特点**:
- 🔄 自动调用`estimatePSD.m`生成Welch和AR两种PSD估计
- 📊 使用`estimateBandwidthMethods.m`对两种PSD进行带宽估计
- 📈 对比两种PSD估计方法的带宽估计结果
- 🎯 支持独立运行模式（无参数运行）
- 📉 提供详细的可视化对比和统计信息
- ⚙️ 支持所有PSD和带宽估计参数的可选配置

**输入参数**:
| 参数 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `sig_processed` | 向量 | 输入信号（实数或复数） | `Rx_data` |
| `fs` | 标量 | 采样频率（Hz） | `3.84e6` |
| `carrier_count` | 标量 | 子载波数 | `180` |
| `subcarrier_spacing` | 标量 | 子载波间隔（Hz） | `15e3` |
| `varargin` | 名称-值对 | 可选参数（见下表） | - |

**可选参数** (`varargin`):
| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `snr` | 标量 | `20` | 信噪比（dB），用于显示 |
| `fc` | 标量 | `0` | 载波频率（Hz），默认基带 |
| `plot` | 逻辑 | `true` | 是否绘制结果图 |
| `method` | 字符串 | `'threshold'` | 带宽估计方法：`'threshold'`, `'energy'`, `'peak_drop'`, `'rms'`, `'integral'`, `'all'` |
| `threshold` | 标量 | `-3` | 阈值法阈值（dB） |
| `energy_percent` | 标量 | `0.9` | 能量百分比（0-1） |
| `peak_drop_db` | 标量 | `3` | 峰值下降dB值 |
| `welch_window` | 标量 | `100` | Welch算法窗长度 |
| `welch_overlap` | 标量 | `55` | Welch算法重叠样本数 |
| `welch_nfft` | 标量 | `8192` | Welch算法FFT点数 |
| `ar_criterion` | 字符串 | `'AIC'` | AR模型阶数选择准则：`'AIC'` 或 `'FPE'` |

**输出参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `B_welch` | 标量/结构体 | Welch算法PSD的带宽估计（Hz），`method='all'`时为结构体 |
| `B_ar` | 标量/结构体 | AR模型PSD的带宽估计（Hz），`method='all'`时为结构体 |
| `B_ideal` | 标量 | 理论带宽（Hz）= `carrier_count * subcarrier_spacing` |
| `results` | 结构体 | 详细结果，包含`.welch`, `.ar`, `.psd`字段 |

**依赖关系**:
```
estimateBandwidth.m
    ├── estimatePSD.m                [必需]
    └── estimateBandwidthMethods.m   [必需]
```

**内部函数**:
- `printBandwidthResults()`: 打印带宽估计结果

**使用示例**:
```matlab
% 示例1：独立运行模式（自动生成信号）
estimateBandwidth

% 示例2：使用已有信号，所有方法对比
signalGenerate;
[B_w, B_a, B_i, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'snr', targetSNRdB, 'method', 'all', 'plot', true);

% 示例3：使用能量百分比法
[B_w, B_a, B_i, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'method', 'energy', 'energy_percent', 0.9);
```

### 2. estimatePSD.m

**功能**: 使用Welch算法和AR模型法（Burg算法）估计信号功率谱密度。

**函数签名**:
```matlab
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...
    sig_processed, fs, snr, varargin)
```

**主要特点**:
- 📊 提供两种PSD估计方法：Welch算法和AR模型法（Burg算法）
- 🔄 支持独立运行模式（无参数运行）
- 🔍 自动检测工作空间中的信号数据（`Rx_data`或`Tx_data`）
- 🎲 如果没有信号数据，自动调用`signalGenerate.m`生成信号
- 📈 输出归一化的单边谱PSD（dB单位，峰值在0dB）
- ⚙️ 可配置Welch算法和AR模型参数

**输入参数**:
| 参数 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `sig_processed` | 向量 | 输入信号（实数信号） | `Rx_data` |
| `fs` | 标量 | 采样频率（Hz） | `3.84e6` |
| `snr` | 标量 | 信噪比（dB），用于绘图标题 | `15` |
| `varargin` | 名称-值对 | 可选参数（见下表） | - |

**可选参数** (`varargin`):
| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `plot` | 逻辑 | `false` | 是否绘制PSD图 |
| `welch_window` | 标量 | `100` | Welch算法窗长度 |
| `welch_overlap` | 标量 | `55` | Welch算法重叠样本数 |
| `welch_nfft` | 标量 | `8192` | Welch算法FFT点数 |
| `ar_criterion` | 字符串 | `'AIC'` | AR模型阶数选择准则：`'AIC'` 或 `'FPE'` |

**输出参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `Pxx_welch` | 向量 | Welch算法PSD估计值（dB，归一化，峰值在0dB） |
| `f_welch` | 向量 | Welch算法频率向量（Hz，单边谱：0到fs/2） |
| `Pxx_ar` | 向量 | AR模型PSD估计值（dB，归一化，峰值在0dB） |
| `f_ar` | 向量 | AR模型频率向量（Hz，单边谱：0到fs/2） |

**依赖关系**:
```
estimatePSD.m
    ├── signalGenerate.m            [可选，独立运行模式]
    ├── Burg (内部函数)              [必需，AR模型法]
    └── computeARpara (内部函数)     [必需，Burg的子函数]
```

**内部函数**:
- `Burg()`: Burg算法实现AR模型PSD估计
- `computeARpara()`: 计算AR模型参数（Burg的子函数）

**使用示例**:
```matlab
% 示例1：独立运行模式
estimatePSD

% 示例2：使用已有信号
signalGenerate;
[Pxx_w, f_w, Pxx_a, f_a] = estimatePSD(...
    Rx_data, fs, targetSNRdB, 'plot', true);

% 示例3：自定义Welch参数
[Pxx_w, f_w, Pxx_a, f_a] = estimatePSD(...
    Rx_data, fs, targetSNRdB, ...
    'welch_window', 200, 'welch_nfft', 16384);
```

### 3. estimateBandwidthMethods.m

**功能**: 从功率谱密度估计信号带宽，提供5种不同的估计方法。

**函数签名**:
```matlab
[B_estimated, results] = estimateBandwidthMethods(Pxx, f, varargin)
```

**主要特点**:
- 🎯 提供5种带宽估计方法：
  1. **阈值法**（Threshold Method）- 固定阈值或自适应阈值
  2. **能量百分比法**（Energy Percentage Method）- 如90%能量带宽
  3. **峰值下降法**（Peak Drop Method）- 从峰值下降固定dB值
  4. **RMS带宽法**（RMS Bandwidth Method）- 二阶矩法
  5. **积分法**（Integral Method）- 累积功率法
- 📊 支持使用所有方法进行对比（`method='all'`）
- 📈 提供详细的结果结构体
- 🎨 支持可视化输出

**输入参数**:
| 参数 | 类型 | 说明 | 示例值 |
|------|------|------|--------|
| `Pxx` | 向量 | 功率谱密度（dB，归一化） | `Pxx_welch` |
| `f` | 向量 | 对应的频率向量（Hz） | `f_welch` |
| `varargin` | 名称-值对 | 可选参数（见下表） | - |

**可选参数** (`varargin`):
| 参数名 | 类型 | 默认值 | 说明 |
|--------|------|--------|------|
| `method` | 字符串 | `'threshold'` | 估计方法：`'threshold'`, `'energy'`, `'peak_drop'`, `'rms'`, `'integral'`, `'all'` |
| `threshold` | 标量 | `-3` | 阈值法阈值（dB） |
| `energy_percent` | 标量 | `0.9` | 能量百分比（0-1） |
| `peak_drop_db` | 标量 | `3` | 峰值下降dB值 |
| `plot` | 逻辑 | `false` | 是否绘制结果图 |
| `peak_freq` | 标量 | `[]` | 峰值频率（Hz），为空则自动检测 |

**输出参数**:
| 参数 | 类型 | 说明 |
|------|------|------|
| `B_estimated` | 标量/结构体 | 估计的带宽（Hz），`method='all'`时为结构体 |
| `results` | 结构体 | 详细结果，包含`.method`, `.bandwidth`, `.lower_freq`, `.upper_freq`, `.peak_freq`, `.peak_power`等字段 |

**依赖关系**:
```
estimateBandwidthMethods.m
    └── (无外部依赖，独立函数)
```

**内部方法函数**:
- `method_threshold()`: 阈值法实现
- `method_energy()`: 能量百分比法实现
- `method_peak_drop()`: 峰值下降法实现
- `method_rms()`: RMS带宽法实现
- `method_integral()`: 积分法实现
- `plotBandwidthResults()`: 绘图函数

**使用示例**:
```matlab
% 示例1：阈值法
[B, results] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'threshold', 'threshold', -3);

% 示例2：能量百分比法
[B, results] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'energy', 'energy_percent', 0.9);

% 示例3：使用所有方法
[B_all, results_all] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'all', 'plot', true);
```

### 4. signalGenerate.m

**功能**: OFDM信号生成函数（可独立运行），生成发送信号和接收信号。

**函数签名**:
```matlab
% 独立运行模式（无返回值，信号保存在工作空间）
signalGenerate
```

**主要特点**:
- 📡 生成完整的OFDM发送信号（基带实信号，通过共轭对称映射实现）
- 🔄 支持16QAM调制、IFFT、循环前缀、升余弦加窗等完整流程
- 📶 采用LTE风格的符号重叠相加机制
- 🌊 支持信道传输（Jakes瑞利衰落 + AWGN）
- 🎯 可独立运行，生成信号后保存在工作空间变量中
- 📦 内置所有依赖函数（`qam16`, `rcoswindow`, `jakesChannel`），完全独立运行

**输出变量**（保存在工作空间）:
| 变量名 | 类型 | 说明 |
|--------|------|------|
| `Tx_data` | 向量 | 发送信号（行向量） |
| `Rx_data` | 向量 | 接收信号（行向量，如果启用信道传输） |
| `fs` | 标量 | 采样频率（Hz），默认 `3.84e6` |
| `carrier_count` | 标量 | 子载波数，默认 `180` |
| `subcarrier_spacing` | 标量 | 子载波间隔（Hz），默认 `15e3` |
| `targetSNRdB` | 标量 | 目标信噪比（dB），默认 `15` |

**系统参数**（LTE 3MHz标准）:
- 采样频率: 3.84 MHz
- 子载波间隔: 15 kHz
- IFFT点数: 256
- 有效数据子载波数: 180（正频率90 + 负频率90）
- 循环前缀长度: 18个采样点（后续符号）

**依赖关系**:
```
signalGenerate.m
    ├── qam16 (内部函数)            [必需]
    ├── rcoswindow (内部函数)        [必需]
    └── jakesChannel (内部函数)      [可选，如果启用信道]
```

**内部函数**:
- `qam16()`: 16QAM调制函数
- `rcoswindow()`: 升余弦窗函数
- `jakesChannel()`: Jakes瑞利衰落信道模型

**使用示例**:
```matlab
% 示例1：仅生成信号
signalGenerate
% 信号保存在 Tx_data 和 Rx_data 中

% 示例2：生成信号后估计带宽
signalGenerate
[B_w, B_a, B_i, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'snr', targetSNRdB, 'plot', true);
```

## 🚀 使用流程

### 流程1：完整带宽估计流程（推荐）⭐

**适用场景**: 需要完整的带宽估计结果，包括PSD估计和带宽估计。

**方法1：独立运行模式（最简单）**
```matlab
% 直接运行，自动生成信号并估计带宽
estimateBandwidth
```

**方法2：使用已有信号**
```matlab
% 步骤1：生成信号
signalGenerate;

% 步骤2：估计带宽（使用所有方法）
[B_welch, B_ar, B_ideal, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'snr', targetSNRdB, ...
    'plot', true, ...
    'method', 'all');
```

**方法3：自定义参数**
```matlab
signalGenerate;
[B_welch, B_ar, B_ideal, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'snr', targetSNRdB, ...
    'method', 'energy', ...
    'energy_percent', 0.9, ...
    'welch_nfft', 16384, ...
    'ar_criterion', 'FPE', ...
    'plot', true);
```

**流程说明**:
1. `estimateBandwidth.m`调用`estimatePSD.m`进行PSD估计
2. `estimatePSD.m`生成Welch和AR两种PSD估计
3. `estimateBandwidth.m`调用`estimateBandwidthMethods.m`对两种PSD进行带宽估计
4. 对比两种PSD估计方法的带宽估计结果
5. 计算误差和统计信息
6. 输出结果和可视化

**方法2：使用已有信号**

**方法3：自定义参数**

**流程说明**:
1. `estimatePSD.m`使用Welch算法估计PSD
2. `estimatePSD.m`使用AR模型法（Burg算法）估计PSD
3. 输出两种方法的PSD估计结果
4. 可选：绘制PSD对比图

---

### 流程3：从PSD估计带宽

**适用场景**: 已有PSD估计结果，只需要进行带宽估计。

**方法1：使用阈值法**
```matlab
% 假设已有PSD估计结果
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...);

% 使用阈值法
[B, results] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'threshold', ...
    'threshold', -3, ...
    'plot', true);
```

**方法2：使用所有方法对比**
```matlab
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...);

% 使用所有方法
[B_all, results_all] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'all', ...
    'plot', true);
```

**方法3：分别对Welch和AR的PSD进行带宽估计**
```matlab
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...);

% 对Welch PSD估计带宽
[B_welch, results_welch] = estimateBandwidthMethods(...
    Pxx_welch, f_welch, 'method', 'all');

% 对AR PSD估计带宽
[B_ar, results_ar] = estimateBandwidthMethods(...
    Pxx_ar, f_ar, 'method', 'all');
```

**流程说明**:
1. 输入PSD估计结果和频率向量
2. 选择带宽估计方法（或使用所有方法）
3. 输出带宽估计结果和详细结果结构体
4. 可选：绘制带宽估计结果图

addpath('2.带宽估计(功率谱）/');

### 2. 信号生成和独立运行模式

**独立运行模式**:
- `estimateBandwidth.m`和`estimatePSD.m`都支持独立运行模式（无参数运行）
- 独立运行模式会自动检测工作空间中的信号数据（`Rx_data`或`Tx_data`）
- 如果没有信号数据，会自动调用`signalGenerate.m`生成信号

**信号变量优先级**:
1. `Rx_data`（如果存在）
2. `Tx_data`（如果存在）
3. 自动调用`signalGenerate.m`生成信号

**注意事项**:
- 独立运行模式会清空工作空间（`signalGenerate.m`中有`clear all`）
- 建议先运行`signalGenerate`，再调用其他函数
- 或者使用函数返回值，而不是依赖工作空间变量

---

### 3. 参数传递和配置

**参数传递规则**:
- `estimateBandwidth.m`会自动将PSD估计参数传递给`estimatePSD.m`
- `estimateBandwidth.m`会自动将带宽估计参数传递给`estimateBandwidthMethods.m`
- 可以通过`estimateBandwidth.m`的可选参数统一配置所有参数

**推荐做法**:
```matlab
% 通过estimateBandwidth统一配置所有参数
[B_w, B_a, B_i, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'welch_nfft', 16384, ...      % PSD参数
    'method', 'all', ...          % 带宽估计参数
    'threshold', -3);             % 带宽估计参数
```

---

### 4. 输出变量和返回值

**工作空间变量**:
- 所有函数都会在工作空间中创建输出变量
- 独立运行模式主要依赖工作空间变量

**函数返回值**:
- ✅ **推荐使用函数返回值**，而不是依赖工作空间变量
- 函数返回值更可靠，不受工作空间状态影响

**示例**:
```matlab
% 推荐：使用函数返回值
[B_w, B_a, B_i, results] = estimateBandwidth(...);

% 不推荐：依赖工作空间变量
estimateBandwidth;
% 然后使用工作空间中的变量
```

### 5. 可视化和绘图

**绘图控制**:
- `estimateBandwidth.m`: 默认`plot=true`，绘制完整对比图
- `estimatePSD.m`: 默认`plot=false`，不绘制PSD图
- `estimateBandwidthMethods.m`: 默认`plot=false`，不绘制带宽估计图

**禁用绘图**:
```matlab
% 禁用所有绘图
[B_w, B_a, B_i, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'plot', false);
```

**绘图内容**:
- `estimateBandwidth.m`: PSD对比图 + 带宽估计结果对比图 + 统计信息
- `estimatePSD.m`: Welch和AR PSD对比图
- `estimateBandwidthMethods.m`: PSD图 + 带宽估计标记

---

### 6. 信号格式要求

**输入信号格式**:
- `estimateBandwidth.m`: 支持实数或复数信号
- `estimatePSD.m`: 要求实数信号（基带信号）
- `signalGenerate.m`: 生成实数基带信号（通过共轭对称映射）

**信号长度**:
- 建议信号长度足够长（至少几百个采样点）
- 信号长度影响PSD估计的精度和分辨率

---

### 7. 参数选择建议

**Welch算法参数**:
- `welch_window`: 窗长度，建议100-500，影响频率分辨率
- `welch_overlap`: 重叠样本数，建议为窗长度的50-75%
- `welch_nfft`: FFT点数，建议8192或16384，影响频率分辨率

**AR模型参数**:
- `ar_criterion`: 阶数选择准则，`'AIC'`或`'FPE'`，通常`'AIC'`效果更好

**带宽估计方法选择**:
- **阈值法**: 适合有明显边界的信号，需要选择合适的阈值
- **能量百分比法**: 适合需要指定能量占比的场景，常用90%
- **峰值下降法**: 适合有明显峰值的信号，常用3dB
- **RMS带宽法**: 适合高斯型频谱，提供统计意义上的带宽
- **积分法**: 适合需要累积功率的场景

## ❓ 常见问题

### Q1: 独立运行模式找不到信号数据？

**问题**: 运行`estimateBandwidth`或`estimatePSD`时提示找不到信号数据。

**解决方案**:
1. 先运行`signalGenerate`生成信号
2. 或者手动提供信号参数：
```matlab
signalGenerate;
[B_w, B_a, B_i, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing);
```

---

### Q2: 带宽估计结果与理论值差异较大？

**可能原因**:
1. PSD估计参数不合适（如`welch_nfft`太小）
2. 带宽估计方法选择不当
3. 信号质量较差（SNR太低）

**解决方案**:
1. 增加`welch_nfft`提高频率分辨率
2. 尝试不同的带宽估计方法（使用`method='all'`对比）
3. 检查信号质量，提高SNR

---

### Q3: 如何选择合适的带宽估计方法？

**建议**:
1. 先使用`method='all'`对比所有方法
2. 根据应用场景选择：
   - 需要指定能量占比 → 能量百分比法
   - 有明显峰值 → 峰值下降法
   - 需要统计意义 → RMS带宽法
   - 需要简单快速 → 阈值法

---

### Q4: PSD估计结果不平滑？

**可能原因**:
1. Welch算法窗长度太小
2. 信号长度太短
3. SNR太低

**解决方案**:
1. 增加`welch_window`长度
2. 增加信号长度
3. 使用AR模型法（通常更平滑）

---

### Q5: 函数运行速度慢？

**优化建议**:
1. 减少`welch_nfft`（但会影响频率分辨率）
2. 禁用绘图（`plot=false`）
3. 使用单一方法而不是`method='all'`
