## 🎯 概述

本文档说明`2.带宽估计(功率谱）/`目录下的文件结构和依赖关系。该目录包含完整的OFDM信号带宽估计功能，包括功率谱密度估计和带宽估计两个主要步骤。

**目录位置**: `2.带宽估计(功率谱）/`

**主要功能**:
1. 功率谱密度（PSD）估计
2. 从PSD估计信号带宽
3. 完整的带宽估计流程

## 📖 核心文件说明

### 1. estimateBandwidth.m

**功能**: 完整的带宽估计流程，整合PSD估计和带宽估计两个步骤。

**主要特点**:
- 调用`estimatePSD.m`生成两个功率谱（Welch和AR）
- 使用`estimateBandwidthMethods.m`的方法对两个功率谱进行带宽估计
- 对比两种PSD估计方法的带宽估计结果
- 支持独立运行模式（无参数运行）
- 提供详细的可视化对比

**输入参数**:
- `sig_processed`: 输入信号（实数或复数信号）
- `fs`: 采样频率（Hz）
- `carrier_count`: 子载波数
- `subcarrier_spacing`: 子载波间隔（Hz）
- 可选参数：`snr`, `fc`, `plot`, `method`, `threshold`, `energy_percent`, `peak_drop_db`, `welch_window`, `welch_overlap`, `welch_nfft`, `ar_criterion`

**输出参数**:
- `B_welch`: Welch算法PSD的带宽估计结果（Hz）
- `B_ar`: AR模型PSD的带宽估计结果（Hz）
- `B_ideal`: 理论带宽（Hz）
- `results`: 详细结果结构体

**依赖关系**:
```
estimateBandwidth.m
    ├── estimatePSD.m                [必需]
    └── estimateBandwidthMethods.m   [必需]
```

---

### 2. estimatePSD.m

**功能**: 使用Welch算法和AR模型法估计信号功率谱密度。

**主要特点**:
- 提供两种PSD估计方法：Welch算法和AR模型法（Burg算法）
- 支持独立运行模式（无参数运行）
- 自动检测工作空间中的信号数据
- 如果没有信号数据，自动调用`signalGenerate.m`生成信号
- 输出归一化的单边谱PSD（dB单位，峰值在0dB）

**输入参数**:
- `sig_processed`: 输入信号（实数信号）
- `fs`: 采样频率（Hz）
- `snr`: 信噪比（dB）
- 可选参数：`plot`, `welch_window`, `welch_overlap`, `welch_nfft`, `ar_criterion`

**输出参数**:
- `Pxx_welch`: Welch算法PSD估计值（dB，归一化）
- `f_welch`: Welch算法频率向量（Hz，单边谱）
- `Pxx_ar`: AR模型PSD估计值（dB，归一化）
- `f_ar`: AR模型频率向量（Hz，单边谱）

**依赖关系**:
```
estimatePSD.m
    ├── signalGenerate.m            [可选，独立运行模式]
    ├── Burg (内部函数)              [必需，AR模型法]
    └── computeARpara (内部函数)     [必需，Burg的子函数]
```

**内部函数**:
- `Burg()`: Burg算法实现AR模型PSD估计
- `computeARpara()`: 计算AR模型参数（Burg的子函数）

---

### 3. estimateBandwidthMethods.m

**功能**: 从功率谱密度估计信号带宽，提供5种不同的估计方法。

**主要特点**:
- 提供5种带宽估计方法：
  1. 阈值法（Threshold Method）
  2. 能量百分比法（Energy Percentage Method）
  3. 峰值下降法（Peak Drop Method）
  4. RMS带宽法（RMS Bandwidth Method）
  5. 积分法（Integral Method）
- 支持使用所有方法进行对比
- 提供详细的结果结构体
- 支持可视化输出

**输入参数**:
- `Pxx`: 功率谱密度（dB，归一化）
- `f`: 对应的频率向量（Hz）
- 可选参数：`method`, `threshold`, `energy_percent`, `peak_drop_db`, `plot`, `peak_freq`

**输出参数**:
- `B_estimated`: 估计的带宽（Hz，标量或结构体）
- `results`: 详细结果结构体

**依赖关系**:
```
estimateBandwidthMethods.m
    └── (无外部依赖，独立函数)
```

**内部方法函数**:
- `method_threshold()`: 阈值法实现
- `method_energy()`: 能量百分比法实现
- `method_peak_drop()`: 峰值下降法实现
- `method_rms()`: RMS带宽法实现
- `method_integral()`: 积分法实现
- `plotBandwidthResults()`: 绘图函数

---

### 4. signalGenerate.m

**功能**: OFDM信号生成函数（可独立运行），生成发送信号和接收信号。

**主要特点**:
- 生成完整的OFDM发送信号（基带实信号）
- 支持16QAM调制、IFFT、循环前缀、升余弦加窗等完整流程
- 支持信道传输（Jakes瑞利衰落 + AWGN）
- 可独立运行，生成信号后保存在变量`Tx_data`和`Rx_data`中
- 内置所有依赖函数（`qam16`, `rcoswindow`, `jakesChannel`）

**输出变量**:
- `Tx_data`: 发送信号（行向量）
- `Rx_data`: 接收信号（行向量，如果启用信道传输）
- `fs`: 采样频率（Hz）
- `carrier_count`: 子载波数
- `subcarrier_spacing`: 子载波间隔（Hz）
- `targetSNRdB`: 目标信噪比（dB）

**依赖关系**:
```
signalGenerate.m
    ├── qam16 (内部函数)            [必需]
    ├── rcoswindow (内部函数)        [必需]
    └── jakesChannel (内部函数)      [可选，如果启用信道]
```

## 🚀 使用流程

### 流程1：完整带宽估计流程（推荐）

```matlab
% 方法1：独立运行模式（自动生成信号）
estimateBandwidth

% 方法2：使用已有信号
signalGenerate;  % 生成信号
[B_welch, B_ar, B_ideal, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'snr', targetSNRdB, ...
    'plot', true, ...
    'method', 'all');
```

**流程说明**:
1. `estimateBandwidth.m`调用`estimatePSD.m`进行PSD估计
2. `estimatePSD.m`生成Welch和AR两种PSD估计
3. `estimateBandwidth.m`调用`estimateBandwidthMethods.m`对两种PSD进行带宽估计
4. 对比两种PSD估计方法的带宽估计结果
5. 输出结果和可视化

---

### 流程2：仅PSD估计

```matlab
% 方法1：独立运行模式
estimatePSD

% 方法2：使用已有信号
signalGenerate;
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...
    Rx_data, fs, targetSNRdB, ...
    'plot', true);
```

**流程说明**:
1. `estimatePSD.m`使用Welch算法估计PSD
2. `estimatePSD.m`使用AR模型法（Burg算法）估计PSD
3. 输出两种方法的PSD估计结果

---

### 流程3：从PSD估计带宽

```matlab
% 假设已有PSD估计结果
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...);

% 使用阈值法
[B, results] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'threshold', ...
    'threshold', -3);

% 使用所有方法
[B_all, results_all] = estimateBandwidthMethods(Pxx_welch, f_welch, ...
    'method', 'all');
```

**流程说明**:
1. 输入PSD估计结果和频率向量
2. 选择带宽估计方法（或使用所有方法）
3. 输出带宽估计结果和详细结果结构体

## ⚠️ 注意事项

### 1. 文件位置

- 确保所有文件在同一目录下（`2.带宽估计(功率谱）/`）
- 或者确保所有文件在MATLAB路径中

### 2. 信号生成

- `signalGenerate.m`可以独立运行，生成信号
- 如果工作空间中已有`Rx_data`或`Tx_data`，独立运行模式会自动使用
- 如果没有信号数据，独立运行模式会自动调用`signalGenerate.m`

### 3. 参数传递

- `estimateBandwidth.m`会自动将PSD估计参数传递给`estimatePSD.m`
- `estimateBandwidth.m`会自动将带宽估计参数传递给`estimateBandwidthMethods.m`
- 可以通过`estimateBandwidth.m`的可选参数统一配置

### 4. 独立运行模式

- `estimateBandwidth.m`和`estimatePSD.m`都支持独立运行模式
- 独立运行模式会自动检测工作空间中的信号数据
- 如果没有信号数据，会自动调用`signalGenerate.m`生成信号

### 5. 输出变量

- 所有函数都会在工作空间中创建输出变量
- 建议使用函数返回值，而不是依赖工作空间变量

### 6. 可视化

- `estimateBandwidth.m`提供完整的可视化对比
- `estimatePSD.m`提供PSD估计可视化
- `estimateBandwidthMethods.m`提供带宽估计可视化
- 可以通过`'plot', false`禁用绘图
