## 🎯 概述

本文档说明OFDM信号的功率谱密度（Power Spectral Density, PSD）估计方法。PSD估计是带宽估计的基础步骤，提供信号在频域的功率分布信息。

**核心函数**: `estimatePSD.m`

**功能**: 使用两种方法估计信号的功率谱密度：
1. **Welch算法**（周期图平均法）
2. **AR模型法**（自回归模型，使用Burg算法）

---

## 📊 功率谱密度估计方法

### 方法1：Welch算法（周期图平均法）

**原理**: 将信号分段，对每段进行FFT计算周期图，然后对所有周期图进行平均，得到平滑的功率谱估计。

**算法步骤**:
1. 将信号分成多个重叠的段（窗）
2. 对每段应用窗函数（如Hanning窗）
3. 对每段进行FFT，计算周期图
4. 对所有周期图进行平均
5. 归一化并转换为dB单位

**优点**:
- 计算稳定，方差小
- 适合长数据记录
- 对噪声有平滑作用
- MATLAB内置函数`pwelch`实现

**缺点**:
- 频率分辨率受窗长度限制
- 需要较长的数据记录
- 计算复杂度中等

**参数**:
- `welch_window`: 窗长度（样本数），默认100
- `welch_overlap`: 重叠样本数，默认55
- `welch_nfft`: FFT点数，默认8192

---

### 方法2：AR模型法（Burg算法）

**原理**: 将信号建模为自回归（AR）过程，通过估计AR模型参数来计算功率谱密度。使用Burg算法估计AR模型参数。

**算法步骤**:
1. 使用Burg算法估计AR模型参数（反射系数）
2. 根据AIC或FPE准则选择最优模型阶数
3. 计算AR模型的频率响应
4. 根据频率响应计算功率谱密度
5. 归一化并转换为dB单位

**优点**:
- 频率分辨率高（不受数据长度限制）
- 适合短数据记录
- 可以提供精细的频谱细节
- 对峰值检测效果好

**缺点**:
- 需要选择合适的模型阶数
- 计算复杂度较高
- 对模型阶数选择敏感

**参数**:
- `ar_criterion`: 阶数选择准则，`'AIC'`或`'FPE'`，默认`'AIC'`

## 🔍 方法详细说明

### Welch算法详细说明

#### 窗函数选择

- **Hanning窗**: 默认使用，提供良好的频率分辨率和旁瓣抑制
- **窗长度**: 影响频率分辨率和方差
  - 窗越长 → 频率分辨率越高，但方差可能增大
  - 窗越短 → 方差越小，但频率分辨率降低

#### 重叠处理

- **重叠比例**: 通常选择50%-75%重叠
- **作用**: 增加平均的段数，降低方差
- **默认值**: 55个样本重叠（约55%重叠率）

#### FFT点数

- **NFFT**: 影响频率采样密度
- **建议**: NFFT ≥ 窗长度
- **默认值**: 8192点，提供高频率分辨率

#### 单边谱转换

- **实信号特性**: 实信号的频谱是共轭对称的
- **单边谱规则**:
  - DC分量（f=0）：幅度不变
  - 正频率（0 < f < fs/2）：幅度乘以2
  - Nyquist频率（f=fs/2）：幅度不变

---

### AR模型法详细说明

#### Burg算法

**原理**: 通过最小化前向和后向预测误差的平均值来估计反射系数。

**步骤**:
1. 初始化前向和后向预测误差
2. 对每个阶数m（1到p）：
   - 计算反射系数k(m)
   - 更新前向和后向预测误差
   - 更新AR模型系数
3. 计算误差功率

#### 模型阶数选择

**AIC准则（Akaike Information Criterion）**:
```
AIC(k) = N × log(E(k+1)) + 2×k
```
- k: 模型阶数
- E(k+1): k阶对应的误差功率
- N: 数据长度
- 选择使AIC最小的阶数

**FPE准则（Final Prediction Error）**:
```
FPE(k) = E(k+1) × (N + k + 1) / (N - k - 1)
```
- 选择使FPE最小的阶数

**阶数限制**: 通常不超过数据长度的1/3

#### 频率响应计算

- 使用`freqz`函数计算AR模型的频率响应
- 频率采样点数：200,000点（高分辨率）
- 频率范围：0到fs/2（单边谱）

#### 单边谱转换

- 与Welch算法相同的单边谱转换规则
- DC分量和Nyquist频率保持不变
- 正频率部分幅度乘以2

## 💻 使用示例

### 示例1：独立运行模式

```matlab
% 无参数运行，自动检测或生成信号
estimatePSD

% 程序将：
% 1. 检查工作空间中是否有Rx_data或Tx_data
% 2. 如果没有，自动调用signalGenerate.m生成信号
% 3. 进行PSD估计并绘制图形
```

### 示例2：使用接收信号

```matlab
% 生成信号
signalGenerate;

% 使用接收信号进行PSD估计
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...
    Rx_data, fs, targetSNRdB, ...
    'plot', true);
```

### 示例3：自定义Welch算法参数

```matlab
% 自定义Welch算法参数
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...
    Rx_data, fs, targetSNRdB, ...
    'welch_window', 200, ...      % 窗长度200
    'welch_overlap', 100, ...     % 重叠100样本
    'welch_nfft', 16384, ...      % FFT点数16384
    'plot', true);
```

### 示例4：使用AR模型的FPE准则

```matlab
% 使用FPE准则选择AR模型阶数
[Pxx_welch, f_welch, Pxx_ar, f_ar] = estimatePSD(...
    Rx_data, fs, targetSNRdB, ...
    'ar_criterion', 'FPE', ...
    'plot', true);
```

### 示例5：在带宽估计流程中使用

```matlab
% 使用estimateBandwidth.m进行完整流程
[B_welch, B_ar, B_ideal, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'plot', true);

% estimateBandwidth内部会调用estimatePSD
% 然后使用estimateBandwidthMethods进行带宽估计
```

## ⚙️ 参数说明

### 输入参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `sig_processed` | 向量 | 是* | - | 输入信号（实数信号，行向量或列向量） |
| `fs` | 数值 | 是* | - | 采样频率（Hz） |
| `snr` | 数值 | 是* | - | 信噪比（dB），用于绘图标题显示 |
| `plot` | 逻辑 | 否 | `false` | 是否绘制PSD图 |
| `welch_window` | 数值 | 否 | `100` | Welch算法窗长度（样本数） |
| `welch_overlap` | 数值 | 否 | `55` | Welch算法重叠样本数 |
| `welch_nfft` | 数值 | 否 | `8192` | Welch算法FFT点数 |
| `ar_criterion` | 字符串 | 否 | `'AIC'` | AR模型阶数选择准则：`'AIC'`或`'FPE'` |

*注：如果无参数运行（独立运行模式），程序会自动检测或生成信号。

### 输出参数

| 参数名 | 类型 | 说明 |
|--------|------|------|
| `Pxx_welch` | 向量 | Welch算法功率谱密度估计值（dB，归一化，峰值在0dB） |
| `f_welch` | 向量 | Welch算法对应的频率向量（Hz，单边谱：0到fs/2） |
| `Pxx_ar` | 向量 | AR模型功率谱密度估计值（dB，归一化，峰值在0dB） |
| `f_ar` | 向量 | AR模型对应的频率向量（Hz，单边谱：0到fs/2） |

## 📈 输出结果

### PSD输出格式

#### Welch算法输出

```matlab
Pxx_welch = [PSD值1, PSD值2, ..., PSD值N]  % dB单位，归一化
f_welch = [0, Δf, 2Δf, ..., fs/2]          % Hz单位，单边谱
```

- **长度**: `length(f_welch) = welch_nfft/2 + 1`（偶数NFFT）或`(welch_nfft+1)/2`（奇数NFFT）
- **频率分辨率**: `Δf = fs / welch_nfft`
- **归一化**: 峰值在0 dB

#### AR模型法输出

```matlab
Pxx_ar = [PSD值1, PSD值2, ..., PSD值M]  % dB单位，归一化
f_ar = [0, Δf, 2Δf, ..., fs/2]         % Hz单位，单边谱
```

- **长度**: `length(f_ar) = 200000/2 + 1 = 100001`（固定频率采样点数）
- **频率分辨率**: `Δf = fs / 200000`（高分辨率）
- **归一化**: 峰值在0 dB

### 可视化输出

如果`plot=true`，将绘制以下图形：

1. **AR模型功率谱密度估计图**
   - 横轴：频率（Hz）
   - 纵轴：PSD（dB）
   - 标题：包含SNR和模型阶数信息

2. **Welch算法功率谱密度估计图**
   - 横轴：频率（Hz）
   - 纵轴：PSD（dB）
   - 标题：包含SNR信息

3. **OFDM信号频谱图**（使用FFT直接计算）
   - 横轴：频率（MHz）
   - 纵轴：PSD（dB）
   - 单边谱，用于对比

## ⚠️ 注意事项

### 1. 输入信号要求

- **信号类型**: 实数基带信号（通过共轭对称映射实现）
- **信号长度**: 建议至少100个样本，否则可能影响PSD估计精度
- **信号格式**: 行向量或列向量均可，函数会自动处理

### 2. Welch算法参数选择

- **窗长度**: 
  - 太短：频率分辨率低
  - 太长：方差可能增大
  - 建议：根据信号长度和频率分辨率需求选择

- **重叠比例**:
  - 通常选择50%-75%
  - 重叠越多，平均段数越多，方差越小
  - 但计算时间也会增加

- **FFT点数**:
  - 建议：NFFT ≥ 窗长度
  - 越大：频率分辨率越高，但计算时间增加
  - 建议选择2的幂次（如8192, 16384）

### 3. AR模型参数选择

- **阶数选择准则**:
  - AIC准则：通常选择较小的阶数
  - FPE准则：可能选择稍大的阶数
  - 建议：先使用AIC，如果结果不满意再尝试FPE

- **模型阶数限制**:
  - 通常不超过数据长度的1/3
  - 过高的阶数可能导致过拟合

### 4. 单边谱说明

- **实信号特性**: 实信号的频谱是共轭对称的
- **单边谱转换**: 
  - DC分量（f=0）：幅度不变
  - 正频率（0 < f < fs/2）：幅度乘以2
  - Nyquist频率（f=fs/2）：幅度不变
- **目的**: 保持总功率不变，单边谱功率 = 双边谱功率

### 5. 归一化说明

- **归一化方法**: 
  1. 线性功率归一化到最小值（或最大值）
  2. 转换为dB单位
  3. 减去最大值，使峰值在0 dB
- **目的**: 便于对比和可视化

### 6. 方法对比

- **Welch算法**: 
  - 适合长数据记录
  - 计算稳定，方差小
  - 频率分辨率受窗长度限制

- **AR模型法**:
  - 适合短数据记录
  - 频率分辨率高
  - 对峰值检测效果好

- **建议**: 两种方法都使用，对比结果，选择更适合的方法

### 7. 性能考虑

- **计算时间**:
  - Welch算法：中等（取决于窗长度和NFFT）
  - AR模型法：较高（需要估计模型参数和选择阶数）

- **内存占用**:
  - Welch算法：中等（取决于NFFT）
  - AR模型法：较低（固定频率采样点数）
