## 🎯 概述

本文档说明从功率谱密度（PSD）估计信号带宽的多种方法。这些方法适用于OFDM信号和其他宽带信号的带宽估计。

**核心函数**: `estimateBandwidthMethods.m`

**功能**: 提供5种不同的带宽估计方法，可以从功率谱密度中提取信号的有效带宽。

---

## 📊 带宽估计方法

`estimateBandwidthMethods.m` 提供以下5种带宽估计方法：

1. **阈值法（Threshold Method）** - 固定阈值或自适应阈值
2. **能量百分比法（Energy Percentage Method）** - 如90%能量带宽
3. **峰值下降法（Peak Drop Method）** - 从峰值下降固定dB值
4. **RMS带宽法（RMS Bandwidth Method）** - 二阶矩法
5. **积分法（Integral Method）** - 累积功率法

---

## 🔍 方法详细说明

### 方法1：阈值法（Threshold Method）

**原理**: 在功率谱密度中找到功率等于或低于指定阈值（dB）的频率点，带宽为上下边界频率之差。

**算法步骤**:
1. 检测PSD的峰值频率和峰值功率
2. 在峰值左侧（低频侧）找到第一个功率 ≤ 阈值的频率点（下边界）
3. 在峰值右侧（高频侧）找到第一个功率 ≤ 阈值的频率点（上边界）
4. 带宽 = |上边界频率 - 下边界频率|

**适用场景**:
- PSD形状清晰，有明显的主瓣
- 需要快速估计带宽
- 阈值选择合理（通常为-3 dB或-6 dB）

**参数**:
- `threshold`: 阈值（dB），默认-3 dB

**优点**:
- 计算简单快速
- 直观易懂
- 适合主瓣明显的信号

**缺点**:
- 阈值选择对结果影响较大
- 对噪声敏感
- 可能不适用于多峰信号

---

### 方法2：能量百分比法（Energy Percentage Method）

**原理**: 找到包含指定百分比（如90%）总能量的频率范围，带宽为该频率范围。

**算法步骤**:
1. 计算PSD的总能量（线性功率积分）
2. 计算目标能量 = 总能量 × 能量百分比
3. 从峰值频率开始，向两侧扩展，累积能量
4. 当累积能量达到目标能量时，确定带宽边界
5. 带宽 = |上边界频率 - 下边界频率|

**适用场景**:
- 需要能量意义上的带宽定义
- 信号能量分布不均匀
- 需要包含大部分信号能量的带宽

**参数**:
- `energy_percent`: 能量百分比（0-1），默认0.9（90%）

**优点**:
- 物理意义明确（能量带宽）
- 对噪声相对不敏感
- 适合能量分布不均匀的信号

**缺点**:
- 计算复杂度较高
- 需要选择合适的能量百分比

---

### 方法3：峰值下降法（Peak Drop Method）

**原理**: 从峰值功率下降固定dB值，找到对应的频率点，带宽为上下边界频率之差。

**算法步骤**:
1. 检测PSD的峰值频率和峰值功率
2. 计算阈值 = 峰值功率 - 下降dB值
3. 在峰值左侧找到功率 ≤ 阈值的频率点（下边界）
4. 在峰值右侧找到功率 ≤ 阈值的频率点（上边界）
5. 带宽 = |上边界频率 - 下边界频率|

**适用场景**:
- PSD有明显的峰值
- 需要相对峰值功率的带宽定义
- 类似3 dB带宽的定义

**参数**:
- `peak_drop_db`: 峰值下降dB值，默认3 dB

**优点**:
- 相对峰值功率定义，物理意义明确
- 类似3 dB带宽，广泛使用
- 计算简单

**缺点**:
- 对峰值检测精度敏感
- 多峰信号可能不适用

---

### 方法4：RMS带宽法（RMS Bandwidth Method）

**原理**: 基于功率谱密度的二阶矩（方差）计算RMS带宽，反映功率分布的分散程度。

**算法步骤**:
1. 归一化PSD（使其积分为1）
2. 计算一阶矩（中心频率）：f_center = ∫ f · PSD(f) df
3. 计算二阶矩（方差）：σ² = ∫ (f - f_center)² · PSD(f) df
4. RMS带宽 = 2 × √σ²
5. 带宽边界 = f_center ± RMS带宽/2

**适用场景**:
- 需要统计意义上的带宽定义
- 信号功率分布较分散
- 需要中心频率和带宽的统计描述

**参数**:
- 无额外参数

**优点**:
- 统计意义明确（二阶矩）
- 提供中心频率信息
- 适合功率分布分散的信号

**缺点**:
- 计算复杂度较高
- 对PSD形状敏感
- 可能不适用于非对称PSD

---

### 方法5：积分法（Integral Method）

**原理**: 基于累积功率分布，找到峰值两侧各占一定百分比功率的频率范围。

**算法步骤**:
1. 计算累积功率分布（从低频到高频）
2. 找到峰值位置对应的累积功率
3. 定义带宽边界：
   - 下边界：峰值累积功率 - 45%总功率
   - 上边界：峰值累积功率 + 45%总功率
4. 通过插值找到对应的频率点
5. 带宽 = |上边界频率 - 下边界频率|

**适用场景**:
- 需要基于累积功率的带宽定义
- 信号功率分布复杂
- 需要平滑的带宽边界

**参数**:
- 无额外参数（内部使用45%功率比例）

**优点**:
- 基于累积功率，边界平滑
- 适合复杂功率分布
- 提供平滑的带宽估计

**缺点**:
- 计算复杂度较高
- 需要插值计算
- 固定功率比例可能不适用于所有信号

## 💻 使用示例

### 示例1：使用阈值法

```matlab
% 假设已有PSD估计结果 Pxx 和频率向量 f
[Pxx, f] = estimatePSD(Rx_data, fs, targetSNRdB);

% 使用阈值法估计带宽
[B, results] = estimateBandwidthMethods(Pxx, f, ...
    'method', 'threshold', ...
    'threshold', -3, ...
    'plot', true);
```

### 示例2：使用能量百分比法

```matlab
% 使用能量百分比法（90%能量带宽）
[B, results] = estimateBandwidthMethods(Pxx, f, ...
    'method', 'energy', ...
    'energy_percent', 0.9, ...
    'plot', true);
```

### 示例3：使用峰值下降法

```matlab
% 使用峰值下降法（3 dB带宽）
[B, results] = estimateBandwidthMethods(Pxx, f, ...
    'method', 'peak_drop', ...
    'peak_drop_db', 3, ...
    'plot', true);
```

### 示例4：使用所有方法

```matlab
% 使用所有方法进行带宽估计
[B_all, results_all] = estimateBandwidthMethods(Pxx, f, ...
    'method', 'all', ...
    'plot', true);

% 查看所有方法的估计结果
fprintf('阈值法: %.3f MHz\n', B_all.threshold/1e6);
fprintf('能量法: %.3f MHz\n', B_all.energy/1e6);
fprintf('峰值下降法: %.3f MHz\n', B_all.peak_drop/1e6);
fprintf('RMS法: %.3f MHz\n', B_all.rms/1e6);
fprintf('积分法: %.3f MHz\n', B_all.integral/1e6);
fprintf('平均带宽: %.3f MHz\n', B_all.mean/1e6);
fprintf('标准差: %.3f MHz\n', B_all.std/1e6);
```

### 示例5：在完整带宽估计流程中使用

```matlab
% 使用estimateBandwidth.m进行完整流程
[B_welch, B_ar, B_ideal, results] = estimateBandwidth(...
    Rx_data, fs, carrier_count, subcarrier_spacing, ...
    'method', 'all', ...  % 使用所有方法
    'plot', true);
```

## ⚙️ 参数说明

### 输入参数

| 参数名 | 类型 | 必需 | 默认值 | 说明 |
|--------|------|------|--------|------|
| `Pxx` | 向量 | 是 | - | 功率谱密度（dB，归一化，峰值在0dB） |
| `f` | 向量 | 是 | - | 对应的频率向量（Hz） |
| `method` | 字符串 | 否 | `'threshold'` | 估计方法：`'threshold'`, `'energy'`, `'peak_drop'`, `'rms'`, `'integral'`, `'all'` |
| `threshold` | 数值 | 否 | `-3` | 阈值法阈值（dB） |
| `energy_percent` | 数值 | 否 | `0.9` | 能量百分比（0-1），如0.9表示90% |
| `peak_drop_db` | 数值 | 否 | `3` | 峰值下降dB值 |
| `plot` | 逻辑 | 否 | `false` | 是否绘制结果图 |
| `peak_freq` | 数值 | 否 | `[]` | 峰值频率（Hz），如果未提供则自动检测 |

### 输出参数

#### 单一方法输出

- `B_estimated`: 估计的带宽（Hz），标量
- `results`: 详细结果结构体，包含：
  - `method`: 使用的方法名称
  - `bandwidth`: 估计带宽（Hz）
  - `lower_freq`: 下边界频率（Hz）
  - `upper_freq`: 上边界频率（Hz）
  - `peak_freq`: 峰值频率（Hz）
  - `peak_power`: 峰值功率（dB）
  - 方法特定参数（如`threshold`、`energy_percent`等）

#### 所有方法输出（`method='all'`）

- `B_estimated`: 结构体，包含：
  - `threshold`: 阈值法估计带宽（Hz）
  - `energy`: 能量法估计带宽（Hz）
  - `peak_drop`: 峰值下降法估计带宽（Hz）
  - `rms`: RMS法估计带宽（Hz）
  - `integral`: 积分法估计带宽（Hz）
  - `mean`: 平均带宽（Hz，排除异常值后）
  - `std`: 标准差（Hz）
- `results`: 结构体，包含所有方法的详细结果

## ⚠️ 注意事项

### 1. PSD输入要求

- **单位**: PSD应为dB单位，且已归一化（峰值在0 dB）
- **频率范围**: 频率向量f应为单边谱（0到fs/2）
- **长度匹配**: Pxx和f的长度必须相同

### 2. 方法选择建议

- **阈值法**: 适合主瓣明显的信号，快速估计
- **能量法**: 适合能量分布不均匀的信号，物理意义明确
- **峰值下降法**: 类似3 dB带宽，广泛使用
- **RMS法**: 适合需要统计描述的场合
- **积分法**: 适合复杂功率分布

### 3. 参数选择

- **阈值法阈值**: 通常选择-3 dB或-6 dB，需要根据信号特性调整
- **能量百分比**: 通常选择0.9（90%），可根据需要调整
- **峰值下降dB值**: 通常选择3 dB，类似3 dB带宽定义

### 4. 多方法对比

- 建议使用`method='all'`进行多方法对比
- 查看平均带宽和标准差，评估估计的一致性
- 异常值会被自动排除（超出2倍标准差的值）

### 5. 噪声影响

- 高噪声环境下，阈值法和峰值下降法可能受影响较大
- 能量法和积分法对噪声相对不敏感
- RMS法可能受噪声影响，需要平滑的PSD

### 6. 计算复杂度

- **简单方法**: 阈值法、峰值下降法（O(N)）
- **中等复杂度**: 能量法、积分法（O(N)）
- **较高复杂度**: RMS法（需要积分计算）
