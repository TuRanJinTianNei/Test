# 载波频率估计实现说明

## 📋 概述

本项目中的载波频率估计主要基于**循环谱（Cyclic Spectrum）**方法实现，通过分析OFDM信号的循环平稳特性来估计载波频率。实现函数为 `cyclic_spectrum.m`。

## 🔬 算法原理

### 1. 循环谱理论基础

循环谱是分析循环平稳信号的重要工具。对于OFDM信号，由于其具有周期性的统计特性，在循环频率α=0处（即传统功率谱）和α=fc处（载波频率）会出现峰值。

**循环自相关函数**定义为：
```
R_x^α(τ) = E{x(t)x*(t-τ)e^(-j2παt)}
```

**循环谱密度**是循环自相关的傅里叶变换：
```
S_x^α(f) = ∫ R_x^α(τ)e^(-j2πfτ) dτ
```

### 2. 估计方法

本项目采用**平滑周期图法**（Smoothed Periodogram Method）计算循环谱：

1. 对信号进行FFT变换
2. 在不同循环频率α下计算循环相关
3. 通过频率域平滑提高估计精度
4. 提取α=0切片，找到峰值位置估计载波频率

## 💻 代码实现详解

### 函数接口

```matlab
function [ff] = cyclic_spectrum(x, N, fs, M, K)
```

**输入参数**：
- `x`：输入信号（实数信号，已上变频）
- `N`：循环谱估计的数据长度（必须≤信号长度）
- `fs`：采样频率（Hz）
- `M`：平滑长度（时间分辨率×频率分辨率=M）
- `K`：绘图标志（K=1时绘制图形）

**输出参数**：
- `ff`：估计的载波频率（Hz）

### 实现步骤

#### 步骤1：初始化循环频率范围

```matlab
d_alpha = fs/(N);                    % 循环频率分辨率
alpha = -fs:d_alpha:fs;              % 循环频率范围：-fs到fs
a_len = length(alpha);               % 循环频率取值个数
```

- **d_alpha**：循环频率分辨率 = 1/时间分辨率
- **alpha**：循环频率数组，覆盖整个采样频率范围

#### 步骤2：初始化频率采样点

```matlab
f_len = floor(N/M-1)+1;             % 平滑周期图的个数
f = -(fs/2-d_alpha*floor(M/2)) + d_alpha*M*(0:f_len-1);  % 频率采样点
```

- **f_len**：频率采样点个数
- **f**：频率轴采样点位置

#### 步骤3：信号FFT变换

```matlab
X = fftshift(fft(x(1:N)));          % FFT变换并fftshift
X = X';                              % 转置为列向量
```

- 对信号前N个采样点进行FFT
- 使用`fftshift`将零频率移到中心

#### 步骤4：遍历循环频率计算循环谱

```matlab
for alfa = alpha
    interval_f_N = round(abs(alfa)/d_alpha);  % 循环频率对应的频率间隔
    f_N = floor((N-interval_f_N-M)/M)+1;       % 平滑周期的个数
    
    % 构造频率索引矩阵
    t = 1:M*f_N;
    t = reshape(t, M, f_N);
    
    % 计算X1和X2（频率域循环相关）
    X1 = X(t);
    X2 = X(t+interval_f_N);
    
    % 计算循环相关
    St = conj(X1).*X2;              % 共轭相乘
    St = mean(St, 1);               % 平滑平均
    
    % 存储循环谱
    S(i, floor((f_len-f_N)/2)+(1:f_N)) = St/N;
    i = i+1;
end
```

**关键点**：
- **interval_f_N**：当前循环频率α对应的频率域间隔
- **X1和X2**：频率域中相距interval_f_N的两个频段
- **循环相关**：`conj(X1).*X2`计算两个频段的共轭乘积
- **平滑平均**：对M个频率点进行平均，提高估计精度

#### 步骤5：提取α=0切片并插值

```matlab
normal_data = S(floor(length(S(:,1))/2)+1, :);  % 提取α=0的切片
normal_data = interp(normal_data, 100);          % 插值提高分辨率
ff = interp(f, 100);                            % 频率轴也插值
```

- **normal_data**：循环谱在α=0处的二维切片（即传统功率谱）
- **插值**：将数据插值100倍，提高频率分辨率

#### 步骤6：载波频率估计

```matlab
% 找到前半部分的最大值位置
for i=1:length(normal_data)/2
  if(abs(normal_data(i)) == max(abs(normal_data(1,1:length(normal_data)/2))))
      f1 = abs(ff(i));  % 负频率部分的峰值
  end
end

% 找到后半部分的最大值位置
for ii=length(normal_data)/2:length(normal_data)
  if(abs(normal_data(ii)) == max(abs(normal_data(1,length(normal_data)/2:end))))
      f2 = abs(ff(ii));  % 正频率部分的峰值
  end
end

% 载波频率 = 两个峰值的平均值
ff = (f1 + f2)/2;
```

**估计策略**：
1. 由于OFDM信号经过上变频后是实信号，频谱具有共轭对称性
2. 在正频率和负频率部分各有一个峰值
3. 载波频率取两个峰值频率的平均值

#### 步骤7：提取f=fc切片（可选）

```matlab
[as2, as22] = Proximate(10e6, f);  % 找到最接近10MHz的频率索引
data3 = S(:, as2);                  % 提取f=fc处的循环频率切片
normal_data3 = data3/max(data3);    % 归一化
```

- 提取在载波频率fc处的循环频率切片
- 用于分析信号的循环平稳特性

## 🔍 算法特点

### 优点

1. **适用于循环平稳信号**：OFDM信号具有循环平稳特性，循环谱方法非常适合
2. **抗噪声能力强**：通过平滑平均可以提高估计精度
3. **可处理实信号**：适用于上变频后的实信号
4. **可视化效果好**：可以直观观察信号的循环特性

### 局限性

1. **计算复杂度较高**：需要遍历所有循环频率
2. **需要较长数据**：估计精度与数据长度相关
3. **参数选择敏感**：平滑长度M的选择影响估计性能

## 📝 使用示例

### 示例1：AWGN信道下的载波频率估计

```matlab
% 生成OFDM信号
N = 20;
para = 128;
ratio = 1/4;
sig = ofdm(N, para, ratio);

% 上变频到载波频率
fc = 10e6;  % 载波频率10MHz
fs = 40e6;  % 采样频率40MHz
trst_rate = 5e5;  % 符号速率
s_n = ceil(fs/trst_rate);
sign = sig(ones(s_n,1),:);
sign = reshape(sign, 1, s_n*length(sign));
data = sign.*exp(1i*2*pi*fc/fs*(0:length(sign)-1));

% 添加AWGN噪声
data_awgn = awgn(data, 25, 'measured');

% 估计载波频率
Ns = length(sig);  % 循环谱估计的数据长度
M = 16;            % 平滑长度
K = 1;             % 绘图标志
f_estimated = cyclic_spectrum(real(data_awgn), Ns, fs, M, K);

fprintf('真实载波频率: %.2f MHz\n', fc/1e6);
fprintf('估计载波频率: %.2f MHz\n', f_estimated/1e6);
fprintf('估计误差: %.2f kHz\n', abs(f_estimated - fc)/1e3);
```

### 示例2：Rayleigh信道下的载波频率估计

```matlab
% 生成并上变频信号（同上）
data = sign.*exp(1i*2*pi*fc/fs*(0:length(sign)-1));

% 通过Rayleigh信道
itau = floor([0,1e-8,2e-8,5e-8,2e-7,5e-7].*fs);
power = [0,-1.0,-7.0,-10.0,-12.0,-17.0];
fmax = 20;
itn = [10000,20000,30000,40000,50000,60000];

data_rayleigh = MUL_RAYLEIGH(data, itau, power, itn, ...
    length(itau), length(data), 1/fs, fmax, 0);
data_rayleigh = data_rayleigh/std(data_rayleigh);
data_rayleigh = awgn(data_rayleigh, 25, 'measured');

% 估计载波频率
f_rayleigh = cyclic_spectrum(real(data_rayleigh), Ns, fs, M, K);

fprintf('Rayleigh信道下估计载波频率: %.2f MHz\n', f_rayleigh/1e6);
```

## 🔧 参数选择建议

### 数据长度N
- **建议值**：至少包含几个完整的OFDM符号
- **影响**：N越大，频率分辨率越高，但计算量增加

### 平滑长度M
- **建议值**：8-32之间
- **影响**：M越大，平滑效果越好，但频率分辨率降低
- **权衡**：时间分辨率×频率分辨率=M（固定）

### 采样频率fs
- **要求**：满足奈奎斯特定理，fs ≥ 2×信号带宽
- **建议**：fs ≥ 4×载波频率（本项目使用fs=4×fc）

## 📈 性能分析

### 估计精度影响因素

1. **信噪比（SNR）**：SNR越高，估计精度越好
2. **数据长度**：数据越长，频率分辨率越高
3. **平滑参数M**：需要权衡平滑效果和分辨率
4. **信道环境**：Rayleigh信道会降低估计精度

### 典型性能

- **AWGN信道，SNR=25dB**：估计误差通常<1%
- **Rayleigh信道，SNR=25dB**：估计误差通常<3%
