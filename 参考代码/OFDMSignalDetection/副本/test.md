## 🎯 项目概述

`test1.m` 是一个基于MATLAB的**OFDM信号识别与带宽估计**仿真程序，主要完成：

1. **OFDM信号生成**：调用 `PSD_generate` 构造测试信号
2. **输入信号可视化**：绘制上变频并加噪声后的输入信号时域波形和频谱图
3. **Rayleigh信道带宽检测**：通过 `Bandwidth_rate_rayleigh` 计算 Welch 与 AR 两种方法的检测率
4. **功率谱密度估计**：使用 `PSD_OFDM_rayleigh` 生成AR、Welch和FFT三种方法的PSD图形
5. **信号可视化**：绘制输入信号时域/频域图及带宽检测率对比曲线

## ✨ 主要功能

### 1. OFDM信号生成
- 16QAM 调制，默认 128 子载波（如需修改请在脚本内取消注释/设置 `para`）
- 循环前缀比例默认 1/4（同样需取消注释/设置 `ratio` 后生效）
- 载波频率 10 MHz，采样频率 40 MHz，上变频取实部发送

### 2. Rayleigh信道带宽检测
- **AR模型法（Burg）** 与 **Welch算法** 双路带宽估计
- `Bandwidth_rate_rayleigh` 计算 SNR=-4:2:10 dB 下的检测准确率
- `PSD_OFDM_rayleigh` 在指定 SNR（`snr_plot`，默认 20 dB）下输出 PSD 曲线

### 3. 循环谱估计
- 通过 `cyclic_spectrum` 分别对 AWGN 和 Rayleigh 场景求循环频谱
- 支持多普勒、加性噪声和上变频后的实信号

### 4. 高阶累积量敏感性
- `ofdm_dif_para` 评估子载波数量（128/256/512）对四阶累积量估计不确定性的影响

### 5. 信号可视化
- **时域图**：发送/接收波形对比（Rayleigh+AWGN）
- **频域图**：发送/接收功率谱密度对比
- **性能图**：AR vs Welch 带宽检测率曲线

## ⚙️ 系统参数配置

### OFDM信号参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **N** | 20 | OFDM符号数量（构成一个帧结构的OFDM信号的个数） |
| **para** | 128（需在脚本中显式赋值） | 子载波数量（带内数据子载波数量） |
| **ratio** | 1/4（需在脚本中显式赋值） | 循环前缀比例 |
| **M** | 16 | 调制阶数（16QAM调制） |
| **过采样倍数** | 4 | 信号生成时的过采样倍数 |

### 频率参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **fc** | 10 MHz | 载波频率（10e6 Hz） |
| **fs** | 40 MHz | 采样频率（40e6 Hz） |
| **采样率** | 4倍载频 | 满足奈奎斯特定理 |

### 信噪比参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **snr** | -4:2:10 dB | 信噪比范围（从-4dB到10dB，步长为2dB） |
| **snr_plot** | 20 dB | 用于生成PSD图形的SNR值 |
| **snr_plot_signal** | 20 dB | 用于生成输入信号时域频域图的SNR值 |

### Rayleigh信道参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **多径数量** | 6径 | 多径信道路径数 |
| **多径延时 itau** | [0, 400, 800, 2000, 8000, 20000] 样本 | 对应时间：[0, 10, 20, 50, 200, 500] ns |
| **多径功率 power** | [0, -1.0, -7.0, -10.0, -12.0, -17.0] dB | 各径的功率衰减 |
| **fmax** | 20 Hz | 最大多普勒频率 |
| **itn** | [10000, 20000, 30000, 40000, 50000, 60000] | 瑞利信道记录次数数组 |

### 仿真参数

| 参数 | 值 | 说明 |
|------|-----|------|
| **蒙特卡洛次数** | 1次 | Rayleigh信道下每个SNR值重复次数 |

> 提示：`para` 与 `ratio` 在脚本中默认被注释，请根据需要取消注释或在运行前手动赋值，否则依赖函数内部默认值。 

## 🚀 运行方法

### 环境要求

- MATLAB R2014b或更高版本
- Signal Processing Toolbox（信号处理工具箱）
- 确保已将所有相关函数文件添加到MATLAB路径中

### 运行步骤

1. **打开MATLAB，切换到项目目录**：
   ```matlab
   cd test1
   ```

2. **确保所有依赖函数在路径中**：
   ```matlab
   addpath(genpath('.'))
   ```

3. **运行主程序**：
   ```matlab
   test1
   ```

### 运行时间

根据计算机性能，典型运行时间如下：

- **信号生成**：< 1 秒
- **Rayleigh信道带宽检测率计算**：约 10-60 秒
- **PSD图形生成**：< 5 秒
- **时域频域图生成**：< 5 秒
- **总时间**：约 1-2 分钟

## 📊 程序流程

### 阶段1：初始化与参数输出

1. 记录仿真开始时间并打印起止标识
2. 设置/读取系统参数：`N`、`fc`、`fs`、`snr`、`fmax`、`itau`、`power`、`itn`
3. 将当前参数打印到命令窗口

### 阶段2：高阶累积量敏感性测试

1. 调用 `ofdm_dif_para(snr, N, ratio, K)`（`ratio` 需提前赋值）
2. 返回 `V_ofdm128/V_ofdm256/V_ofdm512`，用于评估不同子载波数的累积量不确定性

### 阶段3：循环谱估计

1. 生成 OFDM 信号 `sig = ofdm(N, para, ratio)`，并复制形成连续流
2. 叠加 AWGN 和 Rayleigh 信道，计算 `f_awgn`、`f_rayleigh = cyclic_spectrum(...)`

### 阶段4：OFDM信号生成

1. 调用 `PSD_generate(N)` 生成测试信号 `sig_ofdm`
2. 打印生成耗时

### 阶段5：Rayleigh信道带宽检测率计算

1. 调用 `Bandwidth_rate_rayleigh(sig_ofdm, fc, fs, snr, itau, power, fmax, itn)`
2. 计算 AR/Welch 两种方法的带宽检测率，得到 `B_rate_ar_rayleigh`、`B_rate_welch_rayleigh`
3. 打印计算耗时

### 阶段6：Rayleigh信道PSD图形生成

1. 设定 `snr_plot`（默认 20 dB）
2. 调用 `PSD_OFDM_rayleigh` 生成 AR、Welch、直接 FFT 三幅 PSD 图
3. 打印绘图耗时

### 阶段7：发送/接收信号时域与频域绘图

1. 发送端：上变频后取实部得到 `sig_tx_real`
2. 接收端：通过 Rayleigh 信道并加入 AWGN 得到 `sig_rx`
3. 采样至不超过 10000 点后绘制时域对比；FFT 归一化后绘制频域对比

### 阶段8：性能对比与收尾

1. 绘制“Rayleigh信道下的带宽检测率”对比图（AR vs Welch）
2. 打印绘图耗时、总仿真时间与结束时间
3. 结果保留在工作空间

### 流程图概览

```
开始
  ↓
初始化参数（N, fc, fs, snr, 信道参数等）
  ↓
生成OFDM信号（PSD_generate）
  ↓
生成输入信号图形（时域+频域，标注载波和带宽）
  ↓
┌─────────────────────────────────┐
│ Rayleigh信道带宽检测率计算      │
│ (Bandwidth_rate_rayleigh)       │
│ - 8个SNR值 × 1次重复            │
│ - Welch算法 + AR模型法          │
└─────────────────────────────────┘
  ↓
生成Rayleigh信道PSD图形（3个图）
  ↓
绘制性能对比图（AR vs Welch）
  ↓
输出总仿真时间
  ↓
结束
```

## 📖 结果解读

### 带宽检测准确率

- **理想值**：OFDM信号带宽的理想值为 8 MHz
- **准确率计算**：`准确率 = 1 - |估计值 - 理想值| / 理想值`
- **准确率范围**：0% 到 100%，越接近100%表示估计越准确

### 性能分析要点

1. **信噪比影响**：
   - 通常信噪比越高，带宽估计准确率越高
   - 在低信噪比（< 0 dB）下，估计准确率可能显著下降

2. **算法比较**：
   - **Welch算法**：计算速度快，但在低信噪比下性能可能较差
   - **AR模型法**：通常在高信噪比下性能更好，但计算复杂度较高

3. **信道影响**：
   - **Rayleigh信道**：存在多径衰落和多普勒效应，性能会有所下降
   - 通过对比图可以直观看出两种算法的性能差异

### 输入信号特征

- **时域波形**：显示上变频并加噪声后的完整输入信号时域波形
  - 可以看到OFDM信号的时域结构
  - 信号长度和时长信息显示在标题中
- **频域特征**：
  - 载波频率标注在10 MHz处（红色虚线）
  - 理论带宽范围标注在6-14 MHz（绿色虚线，带宽8 MHz）
  - 频谱归一化到最大值，便于观察信号能量分布

## 🔍 技术细节

### 信号生成流程

1. **数据生成**：生成随机16QAM调制数据
2. **IFFT变换**：将频域数据转换为时域OFDM符号
3. **循环前缀**：添加循环前缀（比例1/4）
4. **补零处理**：符号前后补零（用于测试）
5. **功率归一化**：对信号进行功率归一化

### 信道模型

1. **Rayleigh信道**：
   - 模拟多径传播环境
   - 6条多径，不同延时和功率
   - 考虑多普勒效应（fmax = 20 Hz）

2. **AWGN噪声**：
   - 在Rayleigh信道后添加加性高斯白噪声
   - SNR由用户指定

### 带宽估计方法

1. **AR模型法（Burg算法）**：
   - 使用AIC准则自动选择模型阶数
   - 根据SNR选择不同的阈值点（-6dB、-5dB或-3dB）
   - 计算功率谱密度并提取带宽

2. **Welch算法**：
   - 使用汉宁窗，重叠55个采样点，每段100个采样点
   - 计算功率谱密度
   - 使用-3dB点提取带宽

### 输入信号图形生成

1. **时域图**：
   - 显示完整信号的时域波形（不进行采样）
   - 时间轴转换为微秒单位
   - 标题显示SNR、采样点数和信号时长信息

2. **频域图**：
   - 使用FFT计算频谱，FFT点数选择为2的幂次（`2^nextpow2`）
   - 频率轴转换为MHz单位
   - 功率谱密度归一化到最大值（dB）
   - 标注载波频率（红色虚线）和理论带宽范围（绿色虚线）
