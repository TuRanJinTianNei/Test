# OFDM_DEMO.m 运行说明

## 文档说明

**本文档专门解释 `OFDM_DEMO.m` 中当前激活的功能**（未被注释的代码部分）。

如需了解项目的所有功能（包括被注释掉的功能），请参考 `使用说明.md` 文件。

## 概述

`OFDM_DEMO.m` 是OFDM信号检测与参数估计项目的主演示程序。**当前版本**主要用于演示**带宽估计**功能在不同信道环境下的性能表现。

## 系统参数配置

### OFDM信号参数

- **N** = 20：OFDM符号数量（构成一个帧结构的OFDM信号的个数）
- **para** = 128：子载波数量（带内数据子载波数量，有效数据长度）
- **ratio** = 1/4：循环前缀比例
- **M** = 16：调制阶数（16QAM调制）
- **过采样倍数** = 4：信号生成时的过采样倍数

### 频率参数

- **fc** = 10 MHz：载波频率（10e6 Hz）
- **fs** = 40 MHz：采样频率（40e6 Hz）
- **采样率** = 4倍载频（满足奈奎斯特定理）

### 信噪比参数

- **snr** = -4:2:10 dB：信噪比范围（从-4dB到10dB，步长为2dB）
  - 具体值：[-4, -2, 0, 2, 4, 6, 8, 10] dB
- **snr_plot** = 20 dB：用于生成PSD图形的SNR值（标量）

### Rayleigh信道参数

- **多径数量** = 6径
- **多径延时 itau**（样本数）：
  ```
  [0, 400, 800, 2000, 8000, 20000] 样本
  对应时间：[0, 10, 20, 50, 200, 500] ns
  ```
- **多径功率 power**（dB）：
  ```
  [0, -1.0, -7.0, -10.0, -12.0, -17.0] dB
  ```
- **fmax** = 20 Hz：最大多普勒频率
- **itn**：瑞利信道记录次数数组
  ```
  [10000, 20000, 30000, 40000, 50000, 60000]
  ```

### 仿真参数

- **B_ideal** = 8 MHz：OFDM信号带宽理想值（8e6 Hz）
- **AWGN信道蒙特卡洛次数** = 10次：每个SNR值重复10次
- **Rayleigh信道蒙特卡洛次数** = 1次：每个SNR值重复1次

## 运行方法

### 前置要求

- MATLAB R2014b或更高版本
- Signal Processing Toolbox（信号处理工具箱）
- 确保已将所有相关函数文件添加到MATLAB路径中

### 运行步骤

1. 打开MATLAB，切换到项目目录：
   ```matlab
   cd OFDM_Signal_Detection
   ```
2. 运行主程序：
   ```matlab
   OFDM_DEMO
   ```

## 仿真流程

当前版本的仿真流程如下：

### 阶段1：初始化与参数设置

1. **记录仿真开始时间**
2. **设置系统参数**：
   - OFDM符号数量 N = 20
   - 载波频率 fc = 10 MHz
   - 采样频率 fs = 40 MHz
   - 信噪比范围 snr = -4:2:10 dB
   - Rayleigh信道参数（多径延时、功率、多普勒频率等）
3. **输出仿真参数信息**到命令窗口

#### 阶段2：OFDM信号生成

1. **调用 `PSD_generate(N)` 函数**生成OFDM测试信号
   - 使用16QAM调制
   - 128个子载波
   - 循环前缀比例1/4
   - 4倍过采样
   - 前后补零处理
   - 功率归一化
2. **输出**：`sig_ofdm`（生成的OFDM信号复数向量）

### 阶段3：AWGN信道带宽检测率计算

1. **调用 `Bandwidth_rate()` 函数**
2. **对每个SNR值**（-4到10dB，共8个值）：
   - 重复10次蒙特卡洛仿真
   - 每次调用 `PSD_OFDM()` 进行功率谱估计
   - 使用两种方法：Welch算法和AR模型法（Burg算法）
   - 计算带宽估计值
   - 计算准确率：`准确率 = 1 - |估计值 - 理想值| / 理想值`
3. **对10次结果取平均**，得到该SNR下的平均准确率
4. **自动生成图形**：AWGN信道带宽检测准确率对比图（Welch vs AR）
5. **输出**：
   - `B_rate_welch`：Welch算法准确率数组
   - `B_rate_ar`：AR模型法准确率数组

### 阶段4：Rayleigh信道带宽检测率计算

1. **调用 `Bandwidth_rate_rayleigh()` 函数**
2. **对每个SNR值**（-4到10dB，共8个值）：
   - 重复1次蒙特卡洛仿真
   - 信号通过多径Rayleigh信道（`MUL_RAYLEIGH()`）
   - 添加AWGN噪声
   - 调用 `PSD_OFDM_rayleigh()` 进行功率谱估计
   - 使用两种方法：Welch算法和AR模型法
   - 计算带宽估计值和准确率
3. **输出**：
   - `B_rate_welch_rayleigh`：Welch算法准确率数组
   - `B_rate_ar_rayleigh`：AR模型法准确率数组

### 阶段5：Rayleigh信道PSD图形生成

1. **设置SNR** = 20 dB（用于图形显示）
2. **调用 `PSD_OFDM_rayleigh()` 函数**（K=1，绘制图形）
3. **生成3个图形窗口**：
   - AR模型功率谱密度估计图
   - Welch算法功率谱密度估计图
   - OFDM信号频谱图（直接FFT）
4. **输出**：
   - `B_welch`：Welch算法估计的带宽值
   - `B_ar`：AR模型法估计的带宽值

### 阶段6：性能对比分析

1. **创建新的图形窗口**："不同信道下的带宽检测率对比"
2. **绘制对比曲线**：
   - 红色圆点线：Rayleigh信道AR模型法准确率
   - 黑色叉号线：AWGN信道AR模型法准确率
3. **添加图例、坐标轴标签和网格**

### 阶段7：结果输出

1. **输出总仿真时间**（秒和分钟）
2. **输出结束时间**
3. **所有结果变量保存在工作空间**中

### 流程图概览

```
开始
  ↓
初始化参数（N, fc, fs, snr, 信道参数等）
  ↓
生成OFDM信号（PSD_generate）
  ↓
┌─────────────────────────────────┐
│ AWGN信道带宽检测率计算          │
│ (Bandwidth_rate)                │
│ - 8个SNR值 × 10次重复           │
│ - Welch算法 + AR模型法          │
│ - 生成AWGN信道对比图            │
└─────────────────────────────────┘
  ↓
┌─────────────────────────────────┐
│ Rayleigh信道带宽检测率计算      │
│ (Bandwidth_rate_rayleigh)       │
│ - 8个SNR值 × 1次重复            │
│ - Welch算法 + AR模型法          │
└─────────────────────────────────┘
  ↓
生成Rayleigh信道PSD图形（3个图）
  ↓
绘制性能对比图（AWGN vs Rayleigh）
  ↓
输出总仿真时间
  ↓
结束
```

## 结果解读

### 带宽检测准确率

- **理想值**：OFDM信号带宽的理想值为 8 MHz
- **准确率计算**：`准确率 = 1 - |估计值 - 理想值| / 理想值`
- **准确率范围**：0% 到 100%，越接近100%表示估计越准确

### 性能分析要点

1. **信噪比影响**：

   - 通常信噪比越高，带宽估计准确率越高
   - 在低信噪比（< 0 dB）下，估计准确率可能显著下降
2. **算法比较**：

   - **Welch算法**：计算速度快，但在低信噪比下性能可能较差
   - **AR模型法**：通常在高信噪比下性能更好，但计算复杂度较高
3. **信道影响**：

   - **AWGN信道**：只有加性噪声，性能通常较好
   - **Rayleigh信道**：存在多径衰落和多普勒效应，性能会有所下降
   - 通过对比图可以直观看出两种信道的性能差异

- **信号生成**：< 1 秒

## 故障排除

### 常见问题

1. **函数未找到错误**：

   - 确保所有`.m`文件都在MATLAB路径中
   - 运行前执行：`addpath(genpath('OFDM_Signal_Detection'))`
2. **工具箱缺失错误**：

   - 确保已安装Signal Processing Toolbox
   - 检查：`ver` 命令查看已安装的工具箱
3. **内存不足**：

   - 减少SNR数组的长度
   - 减少蒙特卡洛仿真的重复次数（修改`numb`变量）
4. **图形不显示**：

   - 检查MATLAB图形显示设置
   - 确保`K=1`（图形显示标志）
