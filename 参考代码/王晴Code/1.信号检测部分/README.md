### 功能概述

#### 1. 信号存在性检测

检测接收信号中是否存在OFDM信号。

##### 文件说明

- **`indentify_signal_exist.m`**: 基础版信号存在性检测

  - 适用于单信号场景
  - 信噪比范围：-10dB 到 10dB
  - 使用蒙特卡洛仿真计算检测概率
- **`indentify_signal_exist_2.m`**: 改进版信号存在性检测

  - 信噪比范围：-10dB 到 5dB
  - 优化了检测算法，提高了检测准确率

##### 检测方法

1. **功率谱估计**：使用Welch法对接收信号进行功率谱密度估计
2. **拐点检测**：将功率谱转换为拐点图
3. **二次差分**：对拐点图进行二次差分处理
4. **峰值检测**：使用VPD（Valley-Peak Difference）方法检测峰值点
5. **奇异值判断**：若存在至少两个奇异值大于门限，则判定存在信号

##### 使用方法

```matlab
% 直接运行脚本
indentify_signal_exist.m
% 或
indentify_signal_exist_2.m
```

程序会自动：

- 生成OFDM测试信号
- 添加高斯白噪声（AWGN）
- 执行检测算法
- 绘制检测正确率曲线

##### 参数说明

- `SNR`: 信噪比范围（单位：dB）
- `kkk` 或 `n`: 蒙特卡洛仿真次数
- `SubCarryNN`: 有效子载波数（默认256）
- `SubCarryN`: 总子载波数（默认1024）
- `SymbN`: OFDM符号个数（默认20）
- `ratio`: 循环前缀比例（默认1/4）

##### 准确率计算方法

信号存在性检测的准确率计算方法与信号个数检测类似，采用蒙特卡洛仿真：

1. **检测判断**：若存在至少两个奇异值大于门限，则判定存在信号

   ```matlab
   if h > 1  % h为大于门限的奇异值个数
       indx(p) = 1;  % 检测到信号
   else
       indx(p) = 0;  % 未检测到信号
   end
   ```
2. **准确率计算**：

   ```matlab
   corr(SNR) = sum(indx) / kkk
            = 正确检测次数 / 总仿真次数
   ```

#### 2. 信号个数检测

检测接收信号中包含的OFDM信号个数（主要用于检测两个信号）。

##### 文件说明

- **`indentify_signal_num.m`**: 基础版信号个数检测

  - 测试两个信号的场景
  - 信噪比范围：0dB 到 10dB
- **`indentify_signal_num_plus.m`**: 改进版信号个数检测

  - 优化了算法参数
  - 可设置特定信噪比进行测试

##### 检测方法

1. **功率谱估计**：Welch法功率谱密度估计
2. **拐点检测**：转换为拐点图
3. **二次差分**：对拐点图进行二次差分
4. **峰值检测**：VPD方法检测峰值点
5. **峰值排序**：将峰值点从小到大排列
6. **差分分析**：对峰值点进行差分，找出最大差值作为门限
7. **信号计数**：从后向前计算信号数目

##### 使用方法

```matlab
% 直接运行脚本
indentify_signal_num.m
% 或
indentify_signal_num_plus.m
```

##### 参数说明

- `SNR`: 信噪比范围（单位：dB）
- `kkk`: 蒙特卡洛仿真次数
- `SubCarryNN`: 信号1的有效子载波数（默认256）
- `SubCarryNN2`: 信号2的有效子载波数（默认768）

##### 准确率计算方法

信号检测准确率采用**蒙特卡洛仿真**方法计算，具体流程如下：

1. **双重循环结构**：

   - 外层循环：遍历不同SNR值（0dB到10dB，步长1dB）
   - 内层循环：每个SNR下进行 `kkk` 次独立仿真（默认20次）
2. **单次检测过程**：

   - 生成两个OFDM信号（信号1：256子载波，信号2：768子载波）
   - 添加AWGN噪声（根据当前SNR值）
   - 执行检测算法，计算检测到的信号数 `N_signal`
3. **检测结果判断**：

   ```matlab
   if N_signal == 2
       indx(p) = 1;  % 检测正确
   else
       indx(p) = 0;  % 检测错误
   end
   ```
4. **准确率计算**：

   ```matlab
   corr(SNR) = sum(indx) / kkk
            = 正确检测次数 / 总仿真次数
   ```

**准确率公式**：

```
准确率(SNR) = (检测到2个信号的次数) / (总仿真次数)
```

**示例**：

- 假设 `kkk = 20`，某个SNR下：
  - 20次仿真中，18次检测到2个信号，2次检测错误
  - `sum(indx) = 18`
  - `corr = 18 / 20 = 0.9 = 90%`

**特点**：

- ✅ **统计性**：通过多次独立仿真评估算法性能
- ✅ **鲁棒性**：反映算法在不同噪声条件下的表现
- ✅ **可重复性**：固定随机种子可复现结果
- ✅ **全面性**：覆盖多个SNR值，评估不同噪声水平下的性能

#### 3. 信号重叠性检测

检测两个OFDM信号是否在频域上重叠。

##### 文件说明

- **`indentify_signal_overlap.m`**: 基础版信号重叠性检测

  - 检测两个信号是否重叠
  - 信噪比范围：-5dB 到 10dB
- **`indentify_signal_overlap_2.m`**: 改进版信号重叠性检测

  - 优化了重叠判断算法

##### 检测方法

1. **边界检测**：识别功率谱的四个边界（从左到右记为1、2、3、4号边界）
2. **拐点法**：利用一次拐点法求出1号边界和4号边界
3. **峰值分析**：通过VPD方法检测峰值点
4. **重叠判断**：根据峰值点的位置关系判断信号是否重叠

##### 使用方法

```matlab
% 直接运行脚本
indentify_signal_overlap.m
% 或
indentify_signal_overlap_2.m
```

### 核心算法说明

#### VPD（Valley-Peak Difference）方法

VPD方法用于检测峰值点，主要步骤：

1. **均值滤波**：对数据进行三点均值滤波，减少噪声
2. **峰值检测**：找到局部最大值（峰值）和局部最小值（谷值）
3. **VPD计算**：计算每个峰值与对应谷值的差值
4. **假峰值去除**：去除VPD值过小的假峰值点
5. **迭代优化**：迭代去除假峰值，直到峰值数量稳定

#### 拐点检测算法

使用差分方法检测功率谱分布函数的拐点：

```matlab
n1(i) = 3*(loc(i,2)) - (loc(i-1,2)) - (loc(i-2,2)) - (loc(i-3,2));
n2(i) = loc(i+3,2) + loc(i+2,2) + loc(i+1,2) - 3*(loc(i,2));
d(i) = n2(i) - n1(i);
```

其中 `d(i)` 为拐点检测结果。

#### 功率谱估计

使用Welch法进行功率谱密度估计：

```matlab
window = hanning(150);      % 汉宁窗
noverlap = 50;               % 重叠长度
[Pxx1, f] = pwelch(ReData, window, noverlap, length(ReData), Fs);
Pxx = 10*log10(fftshift(Pxx1));
```

### 准确率计算原理

#### 蒙特卡洛仿真方法

所有检测程序都使用**蒙特卡洛仿真**方法来计算检测准确率，这是一种统计评估方法：

##### 基本流程

```
对于每个SNR值：
    ├─ 初始化：indx = zeros(1, kkk)
    │
    ├─ 进行 kkk 次独立仿真：
    │   ├─ 第1次：生成信号 → 添加噪声 → 检测 → 记录结果 indx(1)
    │   ├─ 第2次：生成信号 → 添加噪声 → 检测 → 记录结果 indx(2)
    │   ├─ ...
    │   └─ 第kkk次：生成信号 → 添加噪声 → 检测 → 记录结果 indx(kkk)
    │
    └─ 计算准确率：corr = sum(indx) / kkk
```

##### 数学表达式

对于每个SNR值 `snr_i`：

```
准确率(snr_i) = (1/kkk) × Σ[k=1 to kkk] I(检测结果_k == 真实值)
```

其中：

- `I(·)` 是指示函数，检测正确时为1，错误时为0
- `kkk` 是蒙特卡洛仿真次数
- `检测结果_k` 是第k次仿真的检测结果
- `真实值` 是已知的真实信号状态（如信号个数、是否存在等）

##### 统计意义

- **大数定律**：当 `kkk` 足够大时，准确率收敛到真实的检测概率
- **置信度**：仿真次数越多，结果越可靠
- **无偏估计**：蒙特卡洛方法提供无偏的统计估计

##### 参数选择建议

- **仿真次数 `kkk`**：

  - 推荐值：20-100次
  - 较少次数（10-20）：快速测试，但统计精度较低
  - 较多次数（100+）：更准确的统计结果，但计算时间更长
- **SNR范围**：

  - 根据实际应用场景选择
  - 通常覆盖：低SNR（-10dB到0dB）、中SNR（0dB到10dB）、高SNR（10dB以上）

### 注意事项

1. **运行环境**：需要MATLAB R2016b或更高版本
2. **工具箱要求**：
   - Signal Processing Toolbox（用于`pwelch`、`hanning`函数）
   - Communications Toolbox（用于`awgn`函数，如果使用信号生成函数添加噪声）
   - Statistics and Machine Learning Toolbox（用于`awgn`函数，部分版本）
3. **计算时间**：蒙特卡洛仿真次数越多，计算时间越长
4. **参数调整**：可根据实际需求调整信噪比范围和仿真次数
5. **文件编码**：所有文件已转换为UTF-8编码
6. **信号生成**：推荐使用 `generate_OFDM_signal.m` 函数生成信号，避免代码重复

### 算法特点

1. **无需先验信息**：检测算法不需要知道信号的先验信息
2. **低信噪比适应**：在低信噪比（-10dB）下仍能有效检测
3. **鲁棒性强**：使用VPD方法去除假峰值，提高检测准确性
4. **计算效率高**：算法复杂度较低，适合实时应用
